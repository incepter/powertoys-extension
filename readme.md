# Vibe Extensions

This directory contains local browser extensions for Vibe. The primary extension included here is PowerToys — a collection of small, practical tools to speed up everyday browsing tasks.

## PowerToys

- What it is: A Chrome extension with utilities like Enable Inputs, Show Passwords, Design Mode, Reveal Hidden, Highlighter, Export as PDF, Remove Overlays, and New Meet.
- Where to learn more: See the full documentation in `powertoys/README.md`.
- How to install quickly:
  1. Open Chrome and go to `chrome://extensions/`
  2. Enable Developer mode
  3. Click “Load unpacked” and select the `powertoys` folder

Icons in `powertoys/icons/` are placeholders — replace them before publishing.
